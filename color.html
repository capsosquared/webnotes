Color

Hex Color

Hex color is done in a #RRGGBB format, or if you are doing web safe colors, you will do a #RGB format. Syntax is easy: #aaa; or color: #fc8826.

RGBA Color

RGBA color is done in a 0-255 0-255 0-255 0-1 format. This stands for Red Green Blue Alpha. Alpha is opacity. Syntax is more challenging; color: rgba(135, 25, 200, 0.4).
